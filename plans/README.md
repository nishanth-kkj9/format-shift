- **AudioContext not closed on error paths** (finding 8): Low impact — the browser garbage-collects AudioContexts eventually. Not worth the added complexity of try/finally wrapping in every error path.
- **`convertDataDocument` silently swallows errors** (finding 9): Low impact — the fallback to plain text is arguably a feature (graceful degradation). Changing it would require a UX decision about how to surface errors.
- **`isDark` theme toggle is cosmetic** (finding 10): Low impact — the app is designed as dark-first. Making the toggle functional would require a full light-theme CSS pass, which is a design task, not a bug fix.
- **Bundle size 550KB** (finding 7): Medium impact but the fix (code splitting) is a larger architectural change. Deferred — revisit when the app grows more features.
- **Web Worker for heavy conversions** (direction 3): Not worth doing now — the current approach works for typical file sizes, and the added complexity of worker messaging isn't justified yet.
